## 1. 插曲定性：桥日志里的"记忆自语"不是回答

**现象**：日志出现一段英文推理「But the memory says daybook data only covers through
2026-06 (received_date axis presumably; pay_date coverage may differ)…」被误读为
"与本轮无关的回答"。

**定性（三层澄清）**：

| 疑问 | 结论 |
|---|---|
| 它是回答吗 | 不是。是 ask 子代理的 **thinking**（内部推理），`chat_server.py:543` 只把它逐字打点进桥日志 oplog；前端只收到最终解析出的 answer JSON（`chat_server.py:855` 响应已送），卡片上看不到 |
| 它从哪来 | 项目持久记忆 `C:\Users\87239\.claude\projects\D--develop-cube\memory\daybook-demo-data-coverage.md`（2026-09-28 排查"本季度 0 行"后写入），索引行注入 `MEMORY.md`。桥每问 spawn 全新 claude 进程（cwd=D:\develop\cube，`spawn a1 resume=False`），索引自动进上下文——进程级隔离，无上一轮会话残留 |
| 为何本轮想起 | 本轮窗口 2026-01-01~09-28 横跨"有数据区（1-6 月）+无数据区（7-9 月）"，代理核对记忆适用性后决定"不是 0 行、但答案要注明覆盖范围"——最终答案"数据范围"里「演示数据整体仅覆盖至 2026-06，7-9 月无数据属数据范围所致」即其落地 |

**判定**：召回有实际贡献，但代价远超价值——模型花了 5 段思考反复判断适用性。根因有二：
①记忆条目是**症状型表述**（"本季度/本月问 daybook 天然 0 行"是 9-28 问句的形状，不是
事实本身），导致每次都要重新推导"适用 pay_date 轴吗、适用 1-9 月窗口吗"；②**通道错误**
——问数链的口径输入只有 ai_context/口径词典（预置上下文），会话记忆不在其列，
禁令 2 读侧条款直接封死该通道。

**验证补记**：答案断言"7-9 月无数据"时推理过程并未验证（9-28 的按月覆盖 SQL 只验过
received_date 轴）。事后复算：13,029.26 = 3,000（2026-01）+ 7,222（2026-05）+
2,807.26（2026-06）**精确吻合**——结论碰巧为真，但属未验证断言。

## 3. 两条硬禁令

### 禁令 1：严格先加载后思考，禁止重复解析

原则一句话：**输入（预置上下文）继承，推导（自有分析）作废重产**。
预置上下文是桥机械提取自模型文件的输入数据（D3 设计），skill 第 1 步现有规则
（跳过读 `conf/model/**` 直接进解析）本就建立在它之上；作废对象仅限模型自己
在加载 skill 前产出的语义分析、查询设计、计划表草案。

三层落地：

| 层 | 改动 | 落点 |
|---|---|---|
| prompt | 新增**约束 0**（全文见下）；契约复述段头部标注：`以下仅为输出形态兜底，流程与判定一律以 skill 文本为准` | `chat_server.py` `CLAUDE_INSTRUCTION` |
| skill | 第 0 步末尾追加**预置上下文继承/推导作废**条款（全文见下） | `SKILL.md` 第 0 步（:28-30 之后） |
| 回归 | ~~断言：`logs/agent/*.jsonl` 首条 assistant 事件必须是 `Skill(cube-ask)` tool_use~~——**已随 R5 logs/agent 下线撤销，见 §7**（软约束+硬约束两层不受影响，过程人工看 bridge.log [agent] 行） | ~~`regress/`~~ |

桥 prompt **约束 0**：

```
0. 收到本 prompt 后第一个动作必须是调用 Skill(cube-ask)。【预置上下文】是
   输入数据、随 skill 流程消费，不构成提前分析的许可——加载完成前禁止基于它
   做任何语义分析、查询设计或中间输出
```

`SKILL.md` 第 0 步追加条款：

```markdown
- **预置上下文是输入、不是分析**：模型摘要/通道配方/口径词典是桥机械提取自
  模型文件的原文，随 prompt 注入、直接继承，第 1 步以其为唯一事实输入。
  与之相对，**加载本 skill 之前模型自行产出的语义分析、查询设计、计划表草案
  一律作废**——第 1 步基于预置上下文单遍重新产出，禁止把加载前的推导结论
  搬入复述（双重解析实害实测 2026-09-29：加载前自行推导 23.5k 字符，加载后
  第 1 步原样重推 7k）
```

### 禁令 2：严禁写记忆，写文件白名单外全禁

白名单 = `regress/tmp-query-*.json`（用后即删）。口径事实归 ai_context/词典，
不入会话记忆。事实澄清：本轮子代理只写了 tmp-query 文件（合规）；记忆写入发生在
主会话诊断侧——但它能被问数链读到就是污染面，一并封。
