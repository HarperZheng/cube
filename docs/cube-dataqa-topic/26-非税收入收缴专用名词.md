# 业务类

| 序号 | 术语 | 解释 |
| :---: | :--- | :--- |
| 1 | 政府非税收入 | 是指除税收以外，由各级国家机关、事业单位、代行政府职能的社会团体及其他组织依法利用国家权力、政府信誉、国有资源（资产）所有者权益等取得的各项收入。具体包括：行政事业性收费收入、政府性基金收入、罚没收入、国有资源（资产）有偿使用收入、国有资本收益、彩票公益金收入、特许经营收入、中央银行收入、以政府名义接受的捐赠收入、主管部门集中收入、政府收入的利息收入以及其他收入等。 |
| 2 | 代理银行 | 是指与财政部门签订委托代理协议、代理政府非税收入收缴业务的商业银行。 |
| 3 | 财政专户 | 是财政部门在代理银行开设的专用存款账户，用于接受从财政汇缴专户划入和缴款人直接缴入的政府非税收入以及政府非税收入的分成、划解、退付。 |
| 4 | 财政汇缴专户 | 是财政部门为执收单位在代理银行开设的用于非税收入收缴、与财政专户进行清算的专用存款账户，原则上实行日终零余额管理。 |
| 5 | 待解缴科目 | 是由代理银行设立，用于执收单位非税收入的收入收缴，以及与财政专户进行清算的银行科目账户，当日清算为零。 |
| 6 | 预算科目 | 是由代理银行按照规定程序设立，用于记录、反映非税收入缴款、缴库以及与财政专户清算等业务的银行科目。科目命名规则：XXX政府非税收入，XXX表示非税收入资金对应的行政区域，如福建省政府非税收入、河南省政府非税收入。 |
| 7 | 行政区划码 | 是用于区分不同地区、不同级次财政部门的一个基本编码，参照国家标准《中华人民共和国行政区划代码》执行。 |
| 8 | 缴款识别码 | 是控制与追踪每笔政府非税收入执收业务的全国统一标识，是各级财政部门接入使用全国统一缴款渠道的标准化基础，简称缴款码，具体编码规则见附录4。 |
| 9 | 批次号 | 各业务方发起业务时产生的唯一编号，具体编码规则见附录3。 |
| 10 | 收单机构 | 是指直接面向缴款人提供缴款渠道的机构，包括代理银行、第三方支付机构等，负责进行收单交易确认，并将缴款资金及时汇划至指定账户或科目，也可以是收款行。 |
| 11 | 收款行 | 是指财政专户开户银行，负责进行资金到账信息反馈。 |
| 12 | 执收单位 | 是指依据国家法律、行政法规或部门规章的规定，依法行使非税收入征收权的单位，具有法人资格并独立进行财务核算。 |
| 13 | 预算单位 | 与财政有预算经费缴拨关系的机关、事业单位、社会团体和企业。 |
| 14 | 收入项目 | 是指按规定程序由财政和相关部门审批确认后，可用于非税执收单位执收的项目。 |
| 15 | 直接缴库 | 财政非税收入的一种收缴方式，缴款人按照有关规定，直接将应缴款项缴入财政汇缴专户、财政专户或国库单一账户。 |
| 16 | 集中汇缴 | 财政非税收入的一种收缴方式，由执收单位按有关规定，将所收的应缴款项按收入项目汇总缴入财政汇缴专户或财政专户。 |
