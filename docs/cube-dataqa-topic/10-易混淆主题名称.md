# 易混淆主题名称：writeoff 审验主题在库内的 7 个叫法

> 用途：建模问数时避免同义词混淆——同一实体（票据审验）在源库有多个中文叫法，
> 且物理表名前缀（英文 WRITEOFF）与业务名（审验）错位。
> 关联：[09-cube建模总结(p0-p4).md](./09-cube建模总结(p0-p4).md) 方法论
> "核实的最大价值不在确认而在推翻" 的又一实例；P4.5 定案见 [01-design.md](./01-design.md) §5。

---

## 一、命名错位：cube 名 writeoff ≠ 中文业务名 审验

| 视角 | 名称 | 说明 |
|---|---|---|
| 物理表前缀（英文） | `FBE_WRITEOFF`（WRITEOFF = 核销） | cube 名的来源（溯源物理表的工程约定） |
| 表注释（中文） | "票据审验**主表**"、"审验-收入情况"、"审验-票据开具明细" | **业务主名：审验** |
| 状态列 | FCHANGESTATE "1 未审验，2 已审验" | 同样用"审验" |

单看表名会以为主题是"核销"，查注释才知道主题是**票据审验**——"核销"在这张表里
只是属性列（FWRITEOFFTYPE）和一张字典表（FBE_WRITEOFF_KEYWORD）。

**定案（P4.5）**：cube 名 `writeoff`（溯源物理表前缀，与 paybook/cbill/stock/suspicious
同约定）+ title `票据审验`（业务主称呼）+ description 写明错位缘由。
源系统英文叫法不进 title（P0 规则）。

## 二、库内中文名称地图（7 个叫法）

| 中文名 | 在数据库里的位置 | 含义/视角 |
|---|---|---|
| **审验**（主称呼） | 表注释"票据审验主表"；FCHANGESTATE"未审验/已审验"；FCHECKRESULT"审验结果"；FBGNDATE"审验起始日期"；UNE_CBILL / UNE_PAYBOOK 的 FISVERIFICATE"是否已审验" | 对单位票据使用情况的核验单据——**实体本名**，title 取此 |
| **检查** | FBE_WRITEOFF_RECORD"单位票据检查记录"；FBE_WRITEOFF_RESULT"检查结果记录"；结果子表 FDATE"检查日期" | 审验过程的检查动作视角 |
| **核销** | FWRITEOFFTYPE"核销方式 1手动/2自动"；FBE_WRITEOFF_KEYWORD"票据核销关键词"；UNR_DAILY_EBOOK"电子缴款书核销汇总表"；UNR_SUPERVISE_PAID_DETAIL"智能核销序列号" | 票据核销（登记上缴）环节，cube 的一个维度 |
| **冲销** | UNR_DAILY_WRITEOFF"日结冲销明细表"；FBE_WRITEOFF_BILLBALANCE"票据冲销汇总/明细" | 冲销（作废红冲）视角，日结族（UNR_DAILY_*）用这个词 |
| **审核** | FBE_WRITEOFF 的 FCHECKTYPE"审核方式 1手动审核/2自动审核"（仅此列注释） | 同表内混用（见第三节）；审批流域另有所指 |
| **抽验** | FISSPOTCHECK"是否人工抽验 空/0：非人工抽验 1：人工抽验" | 人工抽验标记 |
| **整改** | FISRECTIFY"是否整改合格"；FCHECKRESULT 注释里的"4 整改通过" | 审验发现问题后的整改环节（实测 FCHECKRESULT 只有 1/2/null） |

## 三、"审核"和"审验"是两个概念，别混

- 本表 FCHECKTYPE 列注释写了"审核方式"——同一张表内"审核/审验"混用，是注释侧的不一致；
- 系统里"**审核**"更多属于**审批流域**（单据流转审批，与票据核验无关）：
  - UNE_REFUND 退付单 FCHANGESTATE："1 未审核 2 不需要审核 3 审核退回 4 单位审核通过 31 财政审核退回 64 财政审核通过…"
  - UNE_VIRTUALPAYBOOK_APPLY FSTATE："3 审核通过 4 审核退回"、FCHECKSITU"审核意见"
  - UNE_HBILL / UNE_HBILL_CHANGE FCHANGESTATE："【审核状态】"
- "**审验**"才是本主题的实体本名（一张审验单 = FBE_WRITEOFF 一行）。

**问数规则**：用户说"审核"时先确认语境——审批流问题（通过/退回）走退付/缴款书域；
"审验/检查/核验"类问题走 writeoff 主题。同义词映射见上表。
